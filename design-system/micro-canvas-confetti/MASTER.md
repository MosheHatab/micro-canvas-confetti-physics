## Demo UX rules
- Dedicated stage is the primary tap/click target (required on mobile)
- Desktop: stage + clicks outside controls also burst
- All control sections stay open; compact via denser spacing + 2-col sliders
- Install snippet always reflects live settings (preset, pieces, duration, size, spread, speed, fall, reach, toggles)
- Keyboard shortcuts shown from `md` up only
- Mobile interactive controls ≥ 44px tall
- Preset cards stay selected when settings change
- Short duration = quick end (~1s)
- Spark preset = micro 8-piece pop
